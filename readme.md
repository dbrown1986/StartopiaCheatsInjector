Very early version.
Spawn hook and game pointers found.
ImGUI and wrapper still being worked on.

The concept behind the project is to bypass plain-text script parsing and allow the user to manipulate values, build changers and spawns in real-time using the games function calls executed via a ImGUI interface.

Requires the latest Startopia beta (1.01.1-b3) and windowed mode. Exclusive full-screen not supported at this time, use borderless tools.

When more has been done, I will update this readme.md with more info.
